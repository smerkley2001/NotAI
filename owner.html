1. Connect payments

    Stripe handles card details on its secure checkout page. Keep private keys in Vercel; this dashboard never displays or stores them.

    1. Create your Stripe account. Complete your business, identity and bank details.
    2. Open Stripe API keys. Start with a sandbox/test key.
    3. Open Vercel environment variables. Add STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET, SUPABASE_SERVICE_ROLE_KEY and NOTAI_CHECKOUT_ENABLED=true in the intended environment. Find your server-only Supabase service role key here.
    4. Add a Stripe webhook destination for the endpoint below, then save its signing secret in Vercel. Use the same test/live mode as your API key.

    Events: checkout.session.completed, checkout.session.async_payment_succeeded, checkout.session.expired, checkout.session.async_payment_failed, charge.refunded.

    Enable and configure Stripe Tax before checkout testing. This checkout automatically calculates tax. Open Stripe Tax.

    After changing Vercel variables, redeploy from Deployments, then reload this page. Presence checks do not validate credentials or prove webhook delivery. Before launch, run an isolated test checkout and confirm its paid order, artwork/QR pack and shipment tracking.

    For preview tests, use a separate Supabase database, a test Stripe key, NOTAI_PREVIEW_WRITES=true, and NOTAI_CHECKOUT_RETURN_ORIGIN set to that preview's HTTPS origin. Never use the production database in a preview. Production ordering accepts live keys only. The owner membership must also be created separately in your test database.

    2. Shipping and availability

    Closing ordering stops new checkout requests. Existing payments, orders and shipments remain available.

    3. Products and sizes

    Add one product for each available color and size. Confirm the actual garment, print layout and fulfillment supplier before activating it. Prices are in USD and exclude tax and shipping.

    4. Orders and fulfillment

    Only verified paid orders should be printed. Start production here, then use the fulfillment desk for exact artwork, per-shirt QR files, customer delivery details and tracking.
